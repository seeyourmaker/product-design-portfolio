# Tag

A small, non-interactive chip naming a platform, method or status in a case-study header.

- `.cs-tag`: 1px `line`, `radius-pill`, `micro` type in `ink-muted`, padding `space-8` × `space-12`; rows use `space-8` gaps.
- Replaces `.adapt-tags span`, `.lg-case-intro span` and the other per-page pill tags.
- Consumer supplies: one to three words each, verified facts only.
