# Figure

The frame for every screenshot, capture, video or diagram in a case study.

- `.cs-figure`: `surface-1`, 1px `line`, `radius-md`, `space-20` padding. Media inside: 1px `line`, `radius-sm`, on `surface-3` while loading.
- Optional label above in `eyebrow` / `accent`; caption below in `caption` / `ink-muted`, `space-16` above it.
- Images open the full original in the shared ImageViewer. One figure per case study may tilt -1.5deg with `shadow-evidence`.
- Diagrams inside a Figure are editable HTML/SVG made with the diagram-design skill, styled with these tokens.
- Consumer supplies: media, alt text, caption. Use owner-approved captures only.
