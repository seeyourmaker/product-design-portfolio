# CaseStudyHeader

The one hero opening every case study; only the accent changes between projects.

- Eyebrow: `eyebrow` in `accent`; optional second part in `ink-muted` after a 1px `line` with `space-24` padding.
- Title: `case-title` (`weight-bold`, `tracking-tight`, `leading-title`), sentence case, emphasised words in `<em>` set upright in `accent`. No uppercase titles and no per-project title sizes.
- Lead: `lead` in `ink-soft`, max `prose-max`. Tags: Tag components after `space-24`.
- Hero art (a screenshot or a diagram) follows the header inside a Figure.
- Consumer supplies: eyebrow, title, lead, verified tags. Never invent metrics or roles.
